[읽는 법] Brier 가 결정적이다. ECE 만으로는 '상수는 해상도가 0 이니
          당연하다' 는 반론이 가능하지만 Brier 는 보정과 해상도를
          함께 센다. **대비가 시간분할에서만 나타나야** 시간 이동이
          원인이라는 주장이 선다 — 무작위분할 행을 반드시 함께 읽을 것.

  DILIrank
    시간분할       모델 Brier 0.4271 / ECE 0.4384 / AUROC 0.6476 / BSS -0.2809
      → **모델보다 Brier 가 낮은(더 좋은) 상수 3종**: C0, C1, C2
    무작위분할      모델 Brier 0.2302 / ECE 0.1240 / AUROC 0.7143 / BSS +0.0868
      → 모든 상수보다 모델의 Brier 가 낮다 (정상)
